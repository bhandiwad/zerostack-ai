## 🚀 **QUICK START**

### **Backend Setup**
```bash
cd cluster-api-backend
python src/database/init_db.py  # Initialize database
python src/main.py              # Start API server (port 5000)
```

### **Frontend Setup**
```bash
cd cluster-api-ui
npm install                     # Install dependencies
npm run dev                     # Start UI (port 5173)
```
